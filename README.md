Добро пожаловать в программный комплекс Виртуального музея вычислительной техники. Проект представляет собой полноценное веб-приложение, предназначенное для ознакомления пользователей с историей развития вычислительных приборов и проведения интерактивных экспериментов с серверными эмуляторами старинных устройств.
Ключевой функционал бэкенда

    Авторизация и безопасность: сессионный контроль доступа на базе Flask-Login и криптографическая защита паролей методами шифрования.

    Динамическая витрина: поиск, фильтрация экспонатов, сбор счетчиков просмотров, система оценок и детальных пользовательских отзывов.

    Промышленный REST-API: конечные точки /api/v1/exhibits с ручной валидацией входящих структур JSON (устойчиво к удалению устаревшего reqparser в современных версиях библиотеки Flask-RESTful).


Инструкция по быстрой установке и развертыванию
1. Клонирование и подготовка окружения

Убедитесь, что на вашей локальной машине установлен Python версии 3.10 или выше. Откройте терминал в папке проекта и установите необходимые внешние зависимости:
pip install Flask Flask-SQLAlchemy Flask-Login Flask-WTF Flask-RESTful requests email-validator

2. Запуск веб-сервера приложения

Запустите главный управляющий файл проекта main.py:
python main.py
Сервер успешно инициализирует глобальный контекст SQLAlchemy, подключит REST-API ресурсы и начнет прослушивание входящих сетевых соединений на локальном хосте. Откройте ваш веб-браузер и перейдите по адресу:
http://127.0.0.1:8080/
Руководство по работе со служебными скриптами автоматизации

А. Автономная аналитика и аудит безопасности логов

Для сканирования лог-файла сервера, выявления подозрительных хакерских запросов (wp-admin, .env), подсчета внутренних ошибок бэкенда и создания красивого текстового отчета museum_report.txt, выполните:
python analytics_manager.py

Б. Создание резервной копии базы данных (Backup)

Для мгновенного создания защищенного сжатого ZIP-архива текущего состояния базы данных и удаления старых копий (ротация 5 файлов), запустите модуль архивации:
python backup_manager.py
