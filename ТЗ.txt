1. Оболочка сайта
Обязательно:

Главное меню: Главная, Статьи, Калькулятор, Личный кабинет.

Дополнительно:
Поддержка тёмной/светлой темы (переключатель).

Блок со статьями.

2. Простой дизайн сайта
Обязательно:
Чистый минимализм: не более 2 основных цветов + акцентный.

Белый фон, серые карточки, чёткие шрифты.

Отсутствие нагромождения анимаций.

Контрастные кнопки CTA (например, «Рассчитать», «Добавить статью» для админа).

3. Функция добавления статей
Обязательно:

Форма для добавления статьи: заголовок, краткое описание, полный текст (WYSIWYG редактор), теги, категория.

Возможность загрузить главное изображение (обложку) статьи.

Предпросмотр статьи перед публикацией.

Редактирование и удаление статей.

Отображение даты создания и автора.

Желательно:

Черновики.

Автосохранение черновиков.

Загрузка нескольких изображений в статью (галерея).

4. Сам калькулятор
Обязательно:

Пользователь вводит параметры → получает результат в реальном времени (без перезагрузки страницы).

Формулы хранятся в отдельном файле (чтобы легко менять логику).

Вывод результата

Сохранение истории расчётов.

Желательно:

Визуализация результата (диаграмма, шкала и тд).

5. Написание главных статей
Обязательно:

Не менее 5-10 качественных уникальных статей объёмом от 1500 символов каждая.

Статьи должны быть связаны с тематикой калькулятора.

Каждая статья содержит пример использования калькулятора.

Желательно:

Внутренняя переключение между статьями.

6. Доработка
Обязательно:

Проверка работы

Скорость работы

Ручное тестирование всех функций (калькулятор, добавление статьи, отображение на форуме).

7. Запуск сайта
Обязательно:

Выбор хостинга.

Импорт базы данных (если требуется).

Настройка резервного копирования.

Финальная проверка перед запуском (все ссылки рабочие, формы отправляются).

Дополнительно
1. Рабочий форум
Функции:

Различные разделы (например недавние статьи).

Регистрация обязательна для создания тем/ответов (гости только читают).

Возможность редактировать/удалять свои сообщения.

Роли: админ (удаление любых сообщений), модератор (скрытие тем), пользователь.

Желательно:

Базовый антиспам

Поиск по форуму.

Лайки / рейтинг ответов.

Цитирование и @username.

Прикрепление изображений к посту.

2. Продвинутая работа с пользователями
Функции:

Восстановление пароля.

Личный кабинет: список своих статей , история расчётов, активность на форуме.

Крайне маловероятно:

Двухфакторная аутентификация.
